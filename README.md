# 🌙 LunarScape

**A personal digital space designed for focus, productivity, and simplicity.**

LunarScape is a personal desktop application project built with Flutter. It aims to create a calm and minimal digital environment where everyday information and productivity tools can live in one place.

The project is currently in early development.

## ✨ Vision

LunarScape aims to become a personal digital workspace that combines simplicity, functionality, and a distraction-free experience.

Rather than building a complex application from the beginning, the goal is to start small and gradually develop it into something more useful.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Platform:** Windows (primary development target)

## 🚧 Development Status

LunarScape is currently under active development.

The initial development direction includes:

- [ ] Minimal personal dashboard
- [ ] Greeting and live clock
- [ ] Date display
- [ ] Quick links
- [ ] Daily inspirational quote

Features will be introduced gradually as development progresses.

## 💻 Getting Started

### Prerequisites

Make sure you have installed:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Git](https://git-scm.com/)
- [Visual Studio](https://visualstudio.microsoft.com/) with Desktop development with C++

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/KrisnaFtGemma4/LunarScape.git
   ```

2. Navigate to the project directory:

   ```bash
   cd LunarScape
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run -d windows
   ```
